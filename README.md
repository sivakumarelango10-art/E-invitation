# 💍 Ananya & Kabir — Interactive Luxury Wedding E-Invitation

An interactive, cinematic digital wedding invitation experience built as a luxury mobile-first web app.

![Wedding Invitation Preview](/public/assets/images/hero_couple.jpg)

---

## ✨ Features

- **📱 Mobile-First Cinematic Architecture**: Designed specifically as a luxury physical invitation brought to life on digital devices.
- **✨ Choreographed Opening Cover**: 7-stage timed reveal sequence with gold foil frames and arched photography.
- **💖 Interactive 3 Scratch Hearts**: Smooth HTML5 Canvas gold foil scratch-off physics for **Day (22)**, **Month (NOVEMBER)**, and **Year (2026)** with celebratory gold confetti.
- **📜 Wedding Timeline**: Animated vertical connecting stem line revealing Sangeet, Vedic Vivaha, and Royal Reception.
- **🏰 Destination Venue**: Heritage palace details with direct Google Maps navigation and copy-to-clipboard address.
- **⏳ Live Auspicious Countdown**: Real-time countdown timer to the wedding date with micro-sliding numeric digits.
- **📸 Cherished Memories Slider**: Swipeable/draggable photo gallery with indicator counter and full-screen lightbox modal.
- **💌 Blessings & RSVP**: Rich dark back-page with couple signatures and interactive RSVP confirmation modal.
- **🎵 Ambient Web Audio Engine**: Floating music controller (`♪`) with soft sitar/harp acoustic harmony chords.
- **🧭 Floating Chapter Navigation**: Quick-jump drawer to navigate directly to any chapter of the invitation.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Pure Custom Vanilla CSS (Design Tokens, GPU-accelerated motion)
- **Audio Engine**: Web Audio API Synthesis (harmonic acoustic sitar/harp drone)
- **Icons & FX**: Lucide React, Canvas Confetti

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production (Vercel / Netlify / Hosting)
```bash
npm run build
```

## ⚙️ Customization

All wedding details (names, dates, locations, photography, schedule, and messages) can be configured in:
`src/config/weddingConfig.js`
